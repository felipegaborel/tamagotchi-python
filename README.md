# Tamagotchi Python

A small Python project for a simple Tamagotchi-style pet simulator.

## Structure

- `src/` - application source code
- `tests/` - unit tests
- `docs/` - documentation
- `data/` - project data
- `images/` - images and assets
- `notebook/` - notebooks

## Run tests

```bash
python -m unittest discover -s tests -v
```
